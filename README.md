# 엘식혜 · L-Sikhye

LCK 경기 결과·밴픽·선수 빌드를 살펴보고 AI 해석을 확인하는 포트폴리오 프로젝트입니다.

## 현재 상태 · 2026-10-07

- React 경기 목록, 세트별 비교, 선수 클릭 빌드 상세를 구현했습니다.
- LCK 포스트시즌 13경기 55세트를 수집했습니다. 기존 2경기 5세트를 포함해 총 15경기 60세트로 API → Firestore → 화면 흐름을 확인했습니다.
- 한글 아이템·룬·스펠 설명, 구매·판매 기록, 스킬 습득 순서를 제공합니다.
- Python 워커가 수집·검증·저장하고, React가 Firestore를 조회합니다. 아이콘과 설명은 경기 패치의 Data Dragon·CommunityDragon 자료를 이용합니다.
- 데이터 변경으로 기존 AI 분석은 재분석 필요 상태일 수 있습니다. 최신 근거로 재생성하는 작업이 남아 있습니다.
- 시즌 전체 수집, 자동 수집, 운영 배포, Spring Boot 인증·승부 예측은 미완료입니다.

## 조회 구조 변경 · 2026-10-07

경기 요약 목록 10개씩 조회, 날짜 필터, 경기 펼치기 시 상세 조회를 구현했습니다. 기존 5세트는 보존하고 요약 2개를 생성했습니다. 적용 절차와 현재 검증 상태는 [조회 분리 기록](docs/series-query-2026-10-07.md)을 참고하세요. 사용자가 새 컬렉션 읽기 규칙을 게시했고 실제 목록·경기 펼치기·세트 전환·선수 상세 표시를 확인했습니다.

## 대회 분류와 팀 로고 · 2026-10-07

2026 시즌의 LCK 정규시즌·포스트시즌·Cup·Road to MSI와 First Stand·MSI·Worlds를 구분합니다. 이번에는 LCK 포스트시즌만 추가 수집했으며, 월즈는 완료 경기 원본이 아직 없어 빈 목록으로 표시합니다. 경기 요약과 상세 결과에 기존 팀 로고를 추가하고, 이미지가 없는 팀은 기본 마크를 표시합니다.

포스트시즌 55세트의 원본 경기 ID와 저장된 ID가 모두 일치하며, 상세 스탯과 타임라인도 55세트에 연결되어 있습니다. Python 25개·프론트엔드 16개 테스트, 린트와 빌드를 통과했습니다. 신규 AI 분석 생성과 자동 수집은 후속 작업입니다. [지원 대회·수집 기록](docs/competition-scope-2026.md)을 참고하세요.

## 수집 안정화 · 2026-10-07

collect.py로 대회 전체 완료 세트를 탐색하고, 이미 저장된 시리즈를 건너뛰며, 실패·중단 항목을 실행 기록에서 재개할 수 있습니다. 시리즈 단위 저장 후 원본 ID와 요약을 대조합니다. --refresh로 원본 수정 사항을 반영합니다. 자동 예약 실행은 후속 작업입니다. [수집 안정화 기록](docs/collection-stability-2026-10-07.md)을 참고하세요.

## 관전자용 AI 분석 · 2026-10-07

짧은 요약·상세 해석·근거 보기와 별도 분석 상태를 구현했습니다. 분석 오류가 경기 데이터 조회에 영향을 주지 않습니다. 실패하던 결승 1·3세트의 분석을 복구하여 4세트 모두 생성·저장했습니다. 1세트에는 사용자가 전달한 나무위키 관전평과 출처가 반영됐습니다. 신규 생성은 Gemini 3.1 Flash-Lite와 GenerateContent의 구조화 응답을 사용하며, 결승 4세트는 간결한 요약·밴픽 포인트·경기 흐름으로 다시 정리했습니다. 화면에서 AI 추정과 기록·작성자 의견 근거를 구분합니다. 전체 자동 분석 운영과 해석 품질 평가는 후속 작업입니다. [AI 연결·검증 기록](docs/ai-review-2026-10-07.md)을 참고하세요.
