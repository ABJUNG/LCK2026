# 관전자용 AI 요약과 상세 해석 · 2026-10-07

## 목표와 구조

관전자용 짧은 요약을 먼저 보여주고 조합·승패 관련 해석을 펼친다. 각 해석에서 사용한 실제 경기 기록을 별도로 확인할 수 있다. 수치 문장은 모델이 만들지 않고 저장된 경기에서 코드가 생성한다. AI는 추정 문장과 근거 ID를 반환한다. 근거 ID 존재와 JSON 형식 검증은 해석의 인과관계 검증과 다르다.

review.py는 저장된 경기에서 대회·패치·진영·승자·선수 KDA/피해량/골드·밴·오브젝트·완료 타임라인을 선별한다. 표시 제목·조회 시각·전체 구매 기록·계정 정보는 전달하지 않는다. 입력 근거의 지문은 별도로 저장해 표시 전용 변경으로 분석을 무효화하지 않는다.

analyze_saved.py는 명시적으로 지정한 시리즈의 최대 5세트만 분석하고 aiReview 필드만 갱신한다. 기본 실행은 AI 호출 없는 대상 미리보기다. 동일 근거·형식 버전의 생성된 분석은 건너뛰며 --force로만 재생성한다. 수집 작업과 별도이므로 AI 실패가 경기 조회·수집을 막지 않는다.

pending → running → generated 또는 failed로 상태를 구분한다. 중단은 pending으로 되돌려 재시도하며 재수집으로 근거가 바뀌면 stale로 표시한다. 저장 직전 트랜잭션에서 근거 지문을 다시 비교해 분석 중 데이터 변경을 감지한다. 오류 원문·키는 저장하지 않는다.

SDK 내부 대기가 길어질 경우를 위해 분석 요청을 별도 프로세스로 실행한다. 세트당 실제 경과 시간 60초를 넘으면 프로세스를 종료하고 TimeoutError 실패 상태로 저장한다. 각 요청의 타임아웃은 30초이며 일시 오류의 재시도는 최대 3번이다. 세트당 총 시간 상한이 우선한다. Windows 제한 환경에서는 별도 프로세스 실행에 권한이 필요할 수 있다.

공식 문서상 GenerateContent는 계속 지원된다. Gemini 3.1 Flash-Lite는 낮은 지연의 요약·추출과 구조화 출력을 지원한다. 같은 실제 입력의 GenerateContent 진단이 약 20초에 완료되어 신규 분석의 기본 경로로 선택했다.
